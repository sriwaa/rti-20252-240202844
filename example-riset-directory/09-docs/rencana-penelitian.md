# Rencana Penelitian: Perbandingan Efisiensi Model Stand-alone (GoPay) dan Super App (DANA)

## 1. Ringkasan

| Item | Keterangan |
|---|---|
| **Judul** | Perbandingan Efisiensi Model Stand-alone (GoPay) dan Super App (DANA) Menggunakan Metrik Time-on-Task pada Mahasiswa UPB |
| **Target Publikasi** | Sinta 2 (Jurnal RESTI/Telematika) atau Scopus Q3-Q4 |
| **Stack & Alat** | Samsung Galaxy A55, Android OS, IBM SPSS Statistics, Excel |
| **Masalah** | Kompleksitas visual Super App memicu information overload -> scanning delay pada mahasiswa UPB -> penurunan efisiensi transaksi harian |
| **Solusi** | Evaluasi eksperimen berpasangan (Within-Subject) + Cold Start Protocol + analisis metrik kuantitatif Time-on-Task |
